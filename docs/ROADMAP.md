# 路线图

## 第一阶段：MVP —— 划词翻译

目标：把"划词"这一个功能做到比欧路好用。

- [x] 插件基础结构（Manifest V3）
- [x] 划词检测：选中文字后，在旁边出现触发按钮/小窗
- [x] 抓取上下文：所在句子、所在段落、网页标题
- [x] 调用 DeepSeek API（OpenAI 兼容格式），**关闭思考模式**
- [x] 流式输出：边生成边显示
- [x] 小窗内容：语境释义、词性、整句翻译、固定搭配
- [x] 剑桥词典跳转按钮（只对单词/短语显示），跳转到词的原形
- [x] 设置页：填写 API Key、选择模型、"查词时自动打开剑桥"开关（默认关）
- [x] 结果缓存：同一内容不重复请求
- [x] 界面：仿 Anthropic 风格，支持深色模式
- [ ] 用真实 API Key 实测（含剑桥链接格式是否正确）
- [ ] 交给 GPT 做一轮代码审查
