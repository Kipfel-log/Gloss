# 路线图

## 第一阶段：MVP —— 划词翻译

目标：把"划词"这一个功能做到比欧路好用。

- [x] 插件基础结构（Manifest V3）
- [x] 划词检测：选中文字后，在旁边出现触发按钮/小窗
- [x] 抓取上下文：所在句子、所在段落、网页标题
- [x] 调用 DeepSeek API（OpenAI 兼容格式），**关闭思考模式**
- [x] 流式输出：边生成边显示
- [x] 小窗内容：语境释义、词性、整句翻译、固定搭配
- [x] 剑桥词典跳转按钮（只对单词/短语显示），跳转到词的原形
- [x] 设置页：填写 API Key、选择模型、"查词时自动打开剑桥"开关（默认关）
- [x] 结果缓存：同一内容不重复请求
- [x] 界面：仿 Anthropic 风格，支持深色模式
- [ ] 用真实 API Key 实测（含剑桥链接格式是否正确）
- [ ] 交给 GPT 做一轮代码审查

## 第二阶段：段落翻译 + 设置升级（v0.2.0）

- [x] 鼠标停在段落上单按 Shift，在段落下方插入译文；再按一次收起
- [x] 附带前一段作为上下文，保证术语和指代一致
- [x] 译文样式（普通 / 淡色 / 虚线下划线 / 左侧竖线 / 浅色底纹）与字号可选，切换实时生效
- [x] 整句翻译可设为"点击后显示"
- [x] 服务商：DeepSeek / 千问（百炼）/ 硅基流动 / 自定义 OpenAI 兼容接口，每家单独保存 Key 和模型
- [x] 去掉 deepseek-v4-pro 预设
- [x] 工具栏小设置弹窗（常用开关）+ 完整设置页（服务商、样式预览、用量）
- [x] 用量记录：每次调用的输入/输出 token、缓存命中、首字与总耗时、失败次数；折线图 + 最近调用表
- [ ] 用真实 Key 实测千问、硅基流动

## v0.3.0：省额度 + 设置整理

- [x] 整句翻译拆成单独请求：关闭"显示整句翻译"时，点了才请求；同一句里查多个词，整句只翻译一次（走缓存）
- [x] 段落译文固定字号（14–18），不再跟着标题变大
- [x] 模型服务改为"自己添加"，没添加的服务商不显示；可移除（同时删除 Key）
- [x] 完整设置页里"用量"移到最上面

## v0.4.0：OpenRouter + 思考强度

- [x] 新增 OpenRouter（预设免费模型；免费额度：未充值每天 50 次，充值 ≥10 credits 后每天 1000 次）
- [x] 每家服务商可调思考强度（关闭 / 低 / 中 / 高），默认关闭
- [x] 用量表增加"思考"token 列
- [x] 图标：两片重叠的手绘色块（GPT 生成，裁大后切成 16 / 32 / 48 / 128），也放进了小设置和完整设置的标题
