划词

选中网页上的英文，显示它在这句话里的意思。

启用 Gloss关闭后划词和段落翻译都会停用
触发方式
显示整句翻译关闭后点“显示整句翻译”才会去翻译，不点就不消耗额度。同一句里查多个词时，整句只翻译一次
只翻译单词和短语开启后，框选整句或一大段文字时不会弹出（习惯性框选时不打扰）；段落翻译用 Shift
查词时自动打开剑桥词典在后台新标签页打开；关闭时可按 Alt + C 或点小窗按钮

段落翻译

鼠标停在段落上，单独按一下 Shift，译文会出现在段落下方；对着原文或译文再按一次就收起。

按 Shift 翻译段落
标注模型和思考档位在译文右下角用小字显示，例如“DeepSeek · deepseek-flash · 思考·低”；展开思考过程时总会显示
译文字号固定大小，不会跟着标题一起变大

备份

把设置导出成一个文件，换文件夹、换电脑或者重装插件之后再导入，就不用重新设置一遍。

包含 API Key导出的文件里 Key 是明文，别发给别人，也别上传到 GitHub
包含用量记录每日汇总和最近的调用明细
导出 / 导入导入会覆盖当前的设置；文件里没有 Key 的话，会保留现在已经填好的 Key
