# Gloss

一个调用自己的大模型 API 的 Chrome 浏览器插件：划词翻译、整段翻译，**结合上下文**给出释义，而不是罗列词典义项。

> Gloss 本义是“行间注释”：以前的人在书页行间给难词写注释，就像在原文下方加译文一样。

## 为什么做这个

现在用的欧路词典插件有两个问题：

1. **反应慢**：划词后要等一会儿才出结果。
2. **不结合上下文**：只给出单词的全部义项，需要自己判断这句话里是哪个意思。

本插件的思路：划词时把**所在句子、所在段落、网页标题**一起发给大模型，直接告诉你"这个词在这句话里是什么意思"；用流式输出 + 小而快的模型 + 缓存来解决速度问题。

## 核心功能

- **划词小窗**：语境释义、词性、整句翻译、固定搭配；流式输出
- **剑桥词典跳转**：单词/短语可一键在剑桥英汉（简体）词典中打开，作为 AI 释义的兜底核对
- **段落翻译**：鼠标停在段落上单按 `Shift`，译文插在段落下方；样式可选
- **多家服务商**：DeepSeek / 千问 / 硅基流动 / OpenRouter（含免费模型）/ Inception（Mercury 扩散模型，可显示扩散过程）/ 自定义 OpenAI 兼容接口；思考强度可调
- **用量统计**：记录每次调用的 token、耗时和估计成本（DeepSeek 预置峰谷价格），折线图一眼看出异常
- **全页双语**：只翻译可见区域的段落（第三阶段）

## 使用范围

- 只支持电脑端 Chrome（及 Chromium 内核浏览器）
- 不做手机端（iOS 安装需要开发者签名，成本过高）

## 安装

1. 下载本仓库（Code → Download ZIP），解压
2. Chrome 地址栏打开 `chrome://extensions`，右上角打开"开发者模式"
3. 点"加载已解压的扩展程序"，选择解压后**含有 `manifest.json` 的那个文件夹**
4. 点工具栏里的 Gloss 图标（可能在拼图图标里）→ "完整设置"，在对应服务商卡片里填入 API Key，点"测试连接"
5. 已经打开的网页需要刷新一次，插件才会生效

更新代码后：在 `chrome://extensions` 里点 Gloss 卡片上的刷新按钮，再刷新网页。

换文件夹、换电脑或重装之前，可以在“完整设置 → 备份”里导出设置，之后再导入。导出文件如果包含 API Key，是明文保存的，不要上传到 GitHub。

## 使用

- 选中网页上的英文 → 点旁边弹出的 Gloss 小图标 → 弹出小窗
  - 选中单词/短语（≤4 个词）：显示词性、语境释义、固定搭配、整句翻译
  - 选中整句或更长内容：显示译文
- `Esc` 关闭小窗；`Alt + C` 在剑桥词典打开当前词
- 鼠标停在段落上单按 `Shift`：翻译该段；再按一次收起
- 框选一段英文后单按 `Shift`：短语模式，讲意思、结构、固定搭配、值得记的词，并给例句
- 点工具栏图标打开小设置；用量和服务商在"完整设置"里

## 目录结构

```
manifest.json        插件清单
src/shared.js        服务商预设与默认设置（后台、设置页共用）
src/background.js    后台：调用模型 API（流式）、缓存、用量记录、打开剑桥词典
src/content.js       网页里：划词小窗、Shift 段落翻译
src/popup.*          工具栏小设置弹窗
src/options.*        完整设置页（服务商、样式、用量图表）
src/ui.*             设置界面共用组件（下拉框、开关等）
docs/                路线图、设计文档
```
