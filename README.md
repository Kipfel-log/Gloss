# Gloss

一个调用自己的大模型 API 的 Chrome 浏览器插件：划词翻译、整段翻译，**结合上下文**给出释义，而不是罗列词典义项。

> Gloss 本义是“行间注释”：以前的人在书页行间给难词写注释，就像在原文下方加译文一样。

## 为什么做这个

现在用的欧路词典插件有两个问题：

1. **反应慢**：划词后要等一会儿才出结果。
2. **不结合上下文**：只给出单词的全部义项，需要自己判断这句话里是哪个意思。

本插件的思路：划词时把**所在句子、所在段落、网页标题**一起发给大模型，直接告诉你"这个词在这句话里是什么意思"；用流式输出 + 小而快的模型 + 缓存来解决速度问题。

## 核心功能

- **划词小窗**：语境释义、词性、整句翻译、固定搭配；流式输出
- **剑桥词典跳转**：单词/短语可一键在剑桥英汉（简体）词典中打开，作为 AI 释义的兜底核对
- **段落翻译**：在段落下方插入译文（第二阶段）
- **全页双语**：只翻译可见区域的段落（第三阶段）

## 使用范围

- 只支持电脑端 Chrome（及 Chromium 内核浏览器）
- 不做手机端（iOS 安装需要开发者签名，成本过高）
- 安装方式：Chrome → 扩展程序 → 开启"开发者模式" → "加载已解压的扩展程序"
